# GNSS/INS/LiDAR 纯测绘联合建图设计

日期：2026-07-15

## 1. 目标与边界

本项目使用 `HKisland_GNSS02.bag` 完成具有绝对测绘坐标的彩色点云建图。算法只在当前 `cehui` 项目中实现，不调用 `mapping-fusion`，但允许使用 Livox LiDAR、Livox IMU 和点云配准算法。

目标如下：

- 使用固定解 RTK 提供绝对位置基准。
- 使用 IMU 和 DJI 姿态提供高频运动传播与扫描去畸变。
- 使用 LiDAR 重叠区域约束修正相邻帧和重复航带之间的相对位姿。
- 使用实测相机标定和时间偏移完成可见性约束下的 RGB 赋色。
- 输出可复核的轨迹、残差、质量报告和 CloudCompare 可直接显示的 RGB PLY。

参考图用于判断岛体轮廓、航带重影和着色是否合理，不作为绝对精度真值。绝对精度必须通过独立控制点、已知检查点或更高精度参考轨迹评估。

## 2. 已确认问题

当前输出与参考图不一致的主要原因已经量化：

- RTK 状态全程为固定解，质量值为 50，但滤波仍使用 `1.5 m` 的位置标准差。当前融合轨迹在 RTK 时刻与 RTK 位置的平均差为 `1.32 m`，最大差为 `2.24 m`。
- 将 RTK 标准差单独改为 `0.05 m` 后，验证轨迹的平均差降为约 `0.22 m`，说明位置权重配置是几何厚壳的重要来源。
- 当前相机轴向与数据集实测 LiDAR 到相机标定相差约 `88.9 deg`。
- 当前流程漏用了 `+0.1 s` 图像时间偏移、镜头畸变和实测相机内参。
- 当前纯测绘输出含 `74,367,651` 个原始点，而视觉参考点云约含 `1,792,808` 个点。未降采样的重复航带放大了厚壳和噪声表现。
- 现有流程没有 LiDAR 点到面约束，无法校正 GNSS/INS 剩余误差导致的航带错层。

## 3. 坐标系约定

统一使用以下符号：

- `n`：本地 ENU 导航坐标系。
- `b`：DJI 机体/导航 IMU 坐标系。
- `l`：Livox LiDAR 坐标系。
- `c`：Hikvision 相机坐标系。

旋转矩阵 `R_ab` 表示将 `b` 系向量变换到 `a` 系。点变换统一写为：

`p_a = R_ab * p_b + t_ab`

所有配置项必须在名称中标明变换方向。读取配置后检查旋转矩阵的正交性、行列式和逆变换一致性；不再接受仅凭设备图片猜测的轴置换作为最终标定。

## 4. 数据输入

使用以下 ROS 话题：

- RTK 位置：`/dji_osdk_ros/rtk_position`
- RTK 速度：`/dji_osdk_ros/rtk_velocity`
- RTK 航向：`/dji_osdk_ros/rtk_yaw`
- RTK 状态：`/dji_osdk_ros/rtk_info_position`、`/dji_osdk_ros/rtk_info_yaw`
- DJI IMU：`/dji_osdk_ros/imu`
- DJI 姿态：`/dji_osdk_ros/attitude`
- Livox IMU：`/livox/imu`
- Livox 点云：`/livox/lidar`
- 相机图像：`/left_camera/image/compressed`

原始消息时间戳、传感器时间戳和每点偏移时间分别保留。任何时间修正只通过显式配置应用，并写入质量报告。

## 5. 联合定位架构

### 5.1 GNSS/INS 初始轨迹

以 KF-GINS 风格误差状态滤波为初始轨迹：

- IMU 负责高频状态传播。
- 固定解 RTK 位置使用厘米级观测噪声；非固定解根据状态动态增大噪声或拒绝更新。
- RTK 速度加入速度观测更新，降低 5 Hz 位置更新之间的漂移和滞后。
- RTK 航向在有效时作为航向观测，约束长期偏航误差。
- 支持 RTK 天线相对机体 IMU 的杆臂补偿。
- 外部 DJI 姿态只作为观测或初始化，不在同一个时刻先覆盖姿态再重复积分陀螺。

输出 `trajectory_nav_initial.csv`、GNSS 位置/速度/航向残差和 IMU 零偏。

### 5.2 LiDAR扫描去畸变

每个 Livox 点使用 `timebase + offset_time` 得到真实采样时刻。根据高频姿态和位置将一帧内所有点补偿到统一参考时刻。优先使用 Livox IMU描述扫描期间的短时角运动，导航轨迹负责绝对姿态和位置基准。

去畸变后过滤盲区、非法点和极端距离点，并生成用于配准的体素降采样点云；原始有效点保留用于最终高密度成图。

### 5.3 LiDAR相对约束

建立关键帧并计算以下约束：

- 相邻关键帧点到面 ICP/GICP 约束。
- 空间接近且时间分离的重复航带约束。
- 仅在几何退化指标、重叠率、收敛状态和残差通过门限时接受约束。

水面、稀疏植被和动态区域不作为强平面约束。配准初值来自 GNSS/INS，搜索范围受测绘先验限制，防止不同岛体之间发生错误闭合。

### 5.4 全局优化

优化状态以关键帧位姿为主，必要时包含速度和 IMU 零偏。因子包括：

- RTK 绝对位置因子。
- RTK 速度和航向因子。
- IMU/导航轨迹相对运动先验。
- LiDAR 相邻帧点到面相对位姿因子。
- 重复航带相对位姿因子。

所有观测使用鲁棒核。RTK 保持绝对坐标基准，LiDAR 只修正局部形变和航带错层，不允许自由缩放地图。

输出 `trajectory_optimized.csv`、每类因子残差、拒绝约束列表和优化前后对比统计。

## 6. 地图生成

使用优化轨迹重新变换全部去畸变 LiDAR 点：

1. 生成保留强度的高密度几何点云。
2. 使用约 `0.15 m` 起始体素进行代表点/质心聚合，目标点数与参考图量级接近，但不以固定点数强行裁剪。
3. 使用半径或统计离群点方法清除孤立点。
4. 保留高密度版和用于检查的稀疏版，避免以显示密度掩盖几何误差。

输出：

- `cloud_geometry_optimized_dense.ply`
- `cloud_geometry_optimized_review.ply`

## 7. 相机赋色

采用数据集实测标定：

- 图像尺寸：`2448 x 2048`
- `fx = 1444.431662789634`
- `fy = 1444.343536688358`
- `cx = 1177.801079401826`
- `cy = 1043.601026568268`
- 畸变：`[-0.05729528706141188, 0.1210407244166642, 0.001274128378760289, 0.0004389741530109464]`
- LiDAR 到相机旋转 `R_cl` 和位移 `P_cl` 使用设备标定配置。
- 图像时间戳应用 `+0.1 s` 偏移。

赋色流程：

1. LiDAR 点按优化轨迹变换到世界坐标。
2. 在图像曝光时刻，将世界点变换到相机坐标。
3. 应用畸变模型和相机内参投影到亚像素坐标。
4. 使用深度缓冲进行遮挡检查。
5. 对可见点进行双线性插值取色。
6. 多帧可见时，优先选择时间差小、视角正、距图像边缘远的观测，并使用稳健颜色融合。

最终 PLY 默认只写 `x y z red green blue`，避免 CloudCompare 自动启用 intensity 标量场覆盖 RGB。

输出：

- `cloud_colorized_optimized_dense.ply`
- `cloud_colorized_optimized_review.ply`
- `colorization_report.json`

## 8. 失败保护

- RTK 状态不满足固定解时自动增大协方差，不伪装成厘米级观测。
- ICP/GICP 不收敛、重叠率不足或位姿改变量超限时拒绝该约束。
- 优化后若 RTK 残差、航带残差或地图范围显著恶化，则保留旧结果并标记运行失败。
- 相机时间差超限、点在相机后方、投影越界或被遮挡时不赋色。
- 输出报告记录所有配置、标定、时间偏移、数据计数和拒绝原因。

## 9. 验收方法

### 自动验收

- 单元测试覆盖坐标变换、时间偏移、畸变投影、双线性插值、遮挡判断和因子残差。
- 固定解 RTK 时，优化轨迹的 RTK 位置残差应显著低于旧流程的 `1.32 m` 平均值。
- 重叠航带点到面 RMSE 在优化后应下降，且不存在异常大位姿跳变。
- PLY 头与实际点数一致，只含 XYZ 和 RGB 字段。
- 颜色覆盖率、被遮挡比例、超时比例和图像边界比例写入报告。

### 人工验收

- CloudCompare 中岛体轮廓与参考图一致，不再出现明显厚壳、扇形条带和独立漂浮建筑。
- 同一岩石、植被和建筑表面的颜色连续，不跨越几何边界。
- 分别检查俯视、侧视和局部剖面，不能只凭单一截图判断。

### 精度说明

在没有控制点或独立真值轨迹时，只能报告内部一致性、RTK拟合残差和航带配准残差，不能将这些指标直接称为绝对建图精度。后续若提供控制点，可增加水平、垂直和三维检查点 RMSE。

## 10. 实施顺序

1. 修正 RTK 状态建模、位置权重、速度/航向观测和姿态重复积分问题。
2. 实现 Livox 扫描去畸变与关键帧数据结构。
3. 实现 LiDAR 相邻帧和重复航带约束。
4. 实现 GNSS/INS/LiDAR 联合优化与质量门限。
5. 在小样本上验证几何后再运行完整包。
6. 接入实测相机标定、时间偏移、畸变、遮挡检查和多视角赋色。
7. 输出完整包高密度版、检查版和质量报告。
