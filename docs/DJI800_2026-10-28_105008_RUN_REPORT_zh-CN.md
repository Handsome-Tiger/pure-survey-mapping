## 长航段安全处理

初始统一配准门限会拒绝部分时间相邻边，使约束图分裂为 48 个连通分量；直接放宽门限会把大旋转 ICP 纳入骨架并产生数十米分段跳变。最终方案采用以下分级策略：

1. 跨航带闭环保持保守门限：内点率不低于 50%、点到面 RMSE 不高于 0.3 m、修正不超过 1.5 m/3°。
2. 时间相邻 ICP 使用原收敛门限；不合格时保留初始 GNSS/INS 相对变换作为强连续性边，但不采用失败 ICP 的变换。
3. 优化前强制检查约束图只有一个连通分量。
4. 优化后同时检查累计修正和相邻修正变化，防止“整体数值可接受但局部断层”的轨迹进入建图。
